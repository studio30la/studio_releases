📊 NetWidget 2.0 — компактный виджет мониторинга сети для Windows

Сделано на Rust + Tauri, без лишних зависимостей. Маленькое прозрачное окно поверх всех окон, которое показывает, кто и сколько тянет интернета.

## Что умеет:

📈 **Трафик по процессам** — скорость загрузки/отдачи и объём для каждого активного процесса, с графиком в реальном времени

🏓 **Мониторинг пинга** — задержка до Google DNS, Cloudflare, AdGuard + свои узлы с графиком истории

🛡 **Проверка IP** — доверие удалённых адресов: организация, страна, репутация

📋 **Журнал трафика** — процессы, превысившие порог, фиксируются автоматически

⚡️ **Завершение процессов** — kill процесса или всего дерева (находит корень, работает даже для браузеров Opera/Chrome и elevated-процессов)

❄️ **Кнопка freeze** — заморозить список процессов, чтобы спокойно нажать «убить»

💡 **Подсказки** — наведи на любую кнопку, узнаешь, что она делает

🎛 **Компактный режим** — сворачивается в минимальный оверлей 340×170

📌 **Поверх всех окон** + сворачивание в сис

## Установка

Скачайте `netwidget.exe` из [релизов](https://github.com/studio30la/NetWidget/releases) и запустите.

## Лицензия

Использование разрешено только для личных целей. Перепродажа и модификация запрещены.
